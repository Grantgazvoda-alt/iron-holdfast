# Feel Audit Plan — Campaign Build
Scope: new campaign layer (campaign-battle, campaign-difficulty, campaign-retention, world-lords, campaign-ui) on the core keep-defense loop. Method: 3 scripted playtest sessions → 5 gated metrics → 3 feel-risk hypotheses.

## 1) Three-session script
**Session A — First 30 seconds (onboard/energize)**
- Fresh run, 4 players, no prior build. Hands-off 5s, then "keep yourself alive, say anything out loud."
- Capture: time-to-first-click, time-to-first-build, dead-air gaps, utterances ("what does the wall do?", "why is gold moving?").
- Probe: "In one word — inviting or punishing?"
- Gate: ≥3/4 place a build ≤15s; ≥2 express budget/army intent. Fail → telegraph/vetting pass.

**Session B — Five-minute campaign**
- Play 5 real minutes to first wave-break + first march budget reached + first close-call.
- Scorecard: first-blank duration, difficulty read (too hard / fair / trivial), any stat-dump read (feels math-driven?), rage-quit or "random" attribution.
- Gate: beachhead/march budget reached ≤ wave 3 OR voiced frustration with concrete cause.

**Session C — World march + supply pressure rotation**
- Rotate supply settings across games (gentle / standard / harsh via difficulty lens). Watch: desertion meltdowns, camp-assault tilt, post-recovery momentum.

## 2) Five auditable metrics + gates
| Metric | Gate | How measured |
|---|---|---|
| M1 Waves survived | ≥7 median by run end; no loss with keep >40% at wave 7 | in-run counters |
| M2 March budget reached | ≥1 run: reach 40%+ of attainable march by wave 4 | march progress log |
| M3 Desertion-recovery | regain 4+ of 6 mass points after ≤50% hit | desertion metric |
| M4 Camp-assault win rate | ≥40% across N audits (camp HP → 0 win path) | outcome log |
| M5 Session length | median 8–14 min (not <4 thin, not >20 bloat) | clock |

≥3/5 to greenlight; M4 is single-blocker.

## 3) Feel-risk hypotheses + tests
- **H1 — Battle math reads stat-y, not tactical.** Test (Session B): after a loss ask "why did you take that?" — player must cite unit property / position / recall, not "bigger number."
- **H2 — Difficulty spikes unannounced.** Test (Session B): play warning-verbatim games; foil wave edge on an indicator ≥30s before cost. Pass if no surprise wipe (>60% team HP loss) without a peekable ramp.
- **H3 — Supply pressure too gentle OR too harsh.** Test (Session C): rotated settings; gate on a viable-feeling "middle ribbon" — players survive ≥5 passes under gentle and soft-reset after melt under harsh.

Exit: keep a daily hold-list; schedule H1/H2/H3 to feel-hold review before the next build commit.
