Iron Holdfast Support

Iron Holdfast is a real-time medieval castle-siege strategy game with command and first-person battle modes.

Basic troubleshooting

If a live siege stops updating, check your internet connection and reopen the game. The authoritative battle simulation runs on the Iron Holdfast server, so an active connection is required during play.

If Battle Mode has no controllable soldier, return to Command Mode and train a living garrison unit first.

If local game identity or preferences become corrupted, clearing the app's local storage will create a new random local player identifier.
