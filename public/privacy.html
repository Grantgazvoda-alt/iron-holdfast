Iron Holdfast Privacy Policy

Effective August 18, 2026

This policy describes the current Iron Holdfast game release for web, iOS, and Android.

Information used by the game

Iron Holdfast creates a random player identifier on your device and stores it locally so the server can maintain your place in a game room. The game sends that identifier, room information, gameplay commands, and game-state messages to the Iron Holdfast game server so multiplayer-style room state and the authoritative simulation can function.

Like most internet services, hosting and security infrastructure may process technical information such as IP address, connection timestamps, request information, and diagnostic logs to deliver the service, prevent abuse, and troubleshoot failures.

What the current release does not include

The current release does not contain third-party advertising SDKs, behavioral advertising, an analytics SDK, a user-account profile system, or in-app purchase code. We do not sell personal information.

Local storage and game state

The random player identifier and selected game preferences are stored on your device using browser/app local storage. Clearing the app's storage removes that local identifier. Server-side room state and operational logs may be retained as needed to operate, secure, and debug the service.

Children

Iron Holdfast is a medieval strategy and combat game and is not designed to collect personal information from children. The game does not provide chat, social profiles, or advertising in the current release.

Changes

If the game later adds accounts, analytics, advertising, purchases, or other data practices, this policy and the applicable app-store privacy disclosures should be updated before that release is published.
