Iron Holdfast Privacy Policy

Effective August 18, 2026

This policy describes the current Iron Holdfast game release for web, iOS, and Android.

Information used by the game

Iron Holdfast creates a random player identifier on your device and stores it locally so the server can maintain your place in a game room. The game sends that identifier, room information, gameplay commands, and game-state messages to the Iron Holdfast game server so room state and the authoritative simulation can function.

The current game server persists room state in per-room storage. That stored state can include the random player identifier, seat/connection ownership information, and game simulation state. The current server source does not define a fixed retention period for that persisted room state.

Hosting and security infrastructure may also process technical information such as IP address, connection timestamps, request information, and diagnostic logs to deliver the service, prevent abuse, and troubleshoot failures. A specific infrastructure-log retention period has not been established in this policy.

What the current release does not include

The current release does not contain third-party advertising SDKs, behavioral advertising, an analytics SDK, a user-account profile system, or in-app purchase code. The current application source contains no advertising or data-sale integration.

Local storage and game state

The random player identifier and selected game preferences are stored on your device using browser/app local storage. Clearing the app's storage removes that local copy. Clearing local app storage does not by itself establish deletion of room state already persisted by the game server.

Children

Iron Holdfast is a medieval strategy and combat game. The current release does not provide chat, social profiles, or advertising.

Changes

If the game later adds accounts, analytics, advertising, purchases, or other data practices, this policy and the applicable app-store privacy disclosures should be updated before that release is published.
